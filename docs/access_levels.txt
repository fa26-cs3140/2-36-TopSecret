USER ACCESS LEVELS (Team Member A)

Access levels
  - There are two levels: ADMIN and STANDARD.
  - Levels are saved in the database (database/missions.db), table user_access:
      username  TEXT PRIMARY KEY
      level     TEXT NOT NULL   (ADMIN or STANDARD)
  - The first user registered in the system is automatically an ADMIN.
    Every user after that is STANDARD.
  - STANDARD users can read items.
    ADMIN users can also create entries, create users, review the audit log,
    and manage access.
  - An admin can promote any standard user to admin, and demote any admin
    to standard, except themselves. This means there is always at least
    one admin.
  - A user does not see menu options they cannot use. The UI calls
    access.isAdmin(username) to decide which options to show.

How it is used
  - The account code calls Access.registerUser(username) when an account is
    created, and again at login (safe to repeat).
  - Admins get a "Manage access" menu option that opens AccessMenu, where they
    can list users, promote a user, or demote an admin.

Classes
  Access      stores and checks levels: registerUser, getLevel, isAdmin,
              promote, demote, getAllUsers
  AccessMenu  admin-only menu to list, promote and demote users
