Database Implementation & Schema Documentation

Team Member A is responsible for adding SQLite to the project, managing connections,
initializing the database table, and importing plain-text mission reports from TSV files.

SQL Schema Definition:

CREATE TABLE IF NOT EXISTS missions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    brief TEXT NOT NULL,
    date TEXT NOT NULL,
    UNIQUE (title, date)
);

Schema Details:
- id (INTEGER): Primary key, automatically increments.
- title (TEXT): Plain-text mission title.
- brief (TEXT): Plain-text body of the mission brief.
- date (TEXT): Plain-text date of the mission.
- UNIQUE (title, date): Constraint preventing duplicate mission imports.
