User Interface Testing Plan

Team Member A is responsible for the command-line interface used
by the user to run the program, handling and verifying user input
and displaying the result.

Planned Tests:

1. Test that a UserInterface object can be made.

2. Test that running the program with no input does not crash.

3. Test that running the program with letters instead of a number
   does not crash.

4. Test that asking for a file number that does not exist does not
   crash.

5. Test that asking for a file number that does exist does not
   crash.

The user interface does not read files or decipher text itself.
It sends requests to ProgramControl, which sends back the result to
be shown to the user.
